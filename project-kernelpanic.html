07 / Survivor Arena

KERNEL PANIC 内核恐慌

二次元动漫风的割草生存 Roguelite：你是系统管理员 @，被困在失控的北京生产节点，用自动火力清剿敌对进程，捡经验数据包、注入升级补丁，活到下一次系统重启。

网页直接试玩下载 Win64 版项目主页

Role / Scope

独立开发
策划 + 程序 + 美术管线

从 PRD、GDD 到 GDScript 实现与 AI 美术资产管线全流程单人完成，数值参数集中在单一配置文件便于持续调优。

  • 引擎Godot 4.7
  • 类型割草生存 Roguelite
  • 平台Web / Windows
  • 状态v2.2 已发布
  • 协议Apache-2.0
A / Fantasy

把「杀进程」做成世界观

敌人是 glitch、疾行、石狮卫士与神龙进程，每次击杀都在终端打印 kill -9 PID —— 主题、美术与反馈语言完全统一。

B / Core Loop

自动火力 + 走位取舍

火力自动清怪，玩家的决策集中在走位、捡取经验数据包与升级补丁的构筑选择，单局节奏紧凑。

C / Build

3 槽位武器 + 12 种补丁构筑

高频扳手、回旋扳手、引雷术三种武器与普通/稀有/史诗三档补丁，配合精英宝箱、磁铁与可破坏物形成 Build 深度。

D / Pipeline

参数集中 + AI 美术管线

全部可调数值收敛到 game_config.gd 单文件；角色逐帧行走动画走 sprite-gen 管线生成，11+ 张 AI 生成资产。

3武器槽位
12升级补丁种类
5:00BOSS 巨型进程王
~1500行 GDScript
11+AI 生成资产
v2.2当前发布版本
